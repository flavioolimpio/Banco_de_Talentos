# Fase 8 — UI: Sidebar, Home com Imagem e Meu Cadastro — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Adicionar sidebar de navegação fixa, imagem ilustrativa na home e página "Meu Cadastro" com 3 abas ao dashboard do candidato.

**Architecture:** Um novo `base_dashboard.html` substitui o padrão `topbar` atual em todos os templates do dashboard (home, formulário, confirmação). A sidebar usa `request.resolver_match.url_name` para destacar o item ativo sem precisar de contexto extra. `MeuCadastroForm` é um `ModelForm` com todos os campos editáveis; a view filtra quais campos renderizar por aba e usa `update_fields` no save para evitar sobrescrever dados de outras abas.

**Tech Stack:** Django 5.2 · Python 3.13 · `django.test.TestCase` · WhiteNoise staticfiles

_ABAS_CAMPOS = {
    "dados": [
        "nome_completo", "telefone", "data_nascimento",
        "rg", "orgao_emissor", "genero", "resumo",
    ],
    "endereco": ["cep", "endereco", "numero", "complemento", "bairro", "cidade", "uf"],

@login_required
@require_http_methods(["GET", "POST"])
def meu_cadastro_view(request):
    aba = request.GET.get("aba", "dados")
    if aba not in _ABAS_CAMPOS:
        aba = "dados"
    campos_aba = _ABAS_CAMPOS[aba]

    form = MeuCadastroForm(request.POST or None, instance=request.user)

    if request.method == "POST" and form.is_valid():
        # Salva apenas os campos da aba atual para não sobrescrever outras abas
        instance = form.save(commit=False)
        instance.save(update_fields=campos_aba)
        audit(request, AuditAction.CADASTRO_ATUALIZADO, alvo=request.user)
        messages.success(request, "Dados atualizados com sucesso.")
        return redirect(f"{reverse('meu_cadastro')}?aba={aba}")

    cpf = request.user.cpf
    cpf_formatado = f"{cpf[:3]}.{cpf[3:6]}.{cpf[6:9]}-{cpf[9:]}"

    return render(request, "usuarios/meu_cadastro.html", {
        "form": form,
        "aba": aba,
        "campos_aba": campos_aba,
        "cpf_formatado": cpf_formatado,
